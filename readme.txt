# 多 Agent 系统设计与实现


---

## 详细版

### 基于 LangGraph 的动态多 Agent 系统设计（个人项目）

**技术栈**：Python / LangGraph / LangChain / LLM API / Checkpointing（持久化）/ 异步并发

**项目描述**：独立设计并实现一套可运行时动态装配的多 Agent 编排框架，采用“专家（Expert）— 专家团（Team）— 主编排器（Supervisor）”三层架构，解决传统单一大图方案中复杂度失控、状态污染、难以复用与测试的问题。

**核心工作与成果**：

- **架构设计**：将系统拆分为“专家—专家团—主编排”三层，每个专家封装为独立编译的 LangGraph 子图，拥有独立的 State Schema、Checkpointer 与中断逻辑，实现复杂度封装与状态隔离，主编排器仅负责意图路由与结果汇总
- **运行时动态加载**：设计“配置 + 图工厂”模式——以声明式 ExpertConfig（提示词/工具/技能/记忆/人审点）描述专家，由图工厂在运行时按需构建并编译子图，配合 `(name, config_hash)` 键的编译缓存与配置热更新，实现“任务到达才装配”
- **统一契约层**：为所有专家子图定义统一的 ExpertInput/ExpertOutput 状态协议与显式映射适配层，保证专家可插拔、可独立替换，子图可脱离主图单独编译测试
- **记忆与人审机制**：通过命名空间化的 thread_id（专家级/团队级/会话级三层）实现多用户会话下专家记忆隔离；对高风险工具节点配置 interrupt_before 实现局部人工审批，支持从子图内部断点恢复
- **多专家协作**：实现 Supervisor 团队图（条件边动态分派）与 Map-Reduce 并行团队两种协作模式，支持多专家并发执行后结果汇总；基于 namespace 流式输出实现前端按专家维度的实时进度展示
- **工程化**：全链路异步化（ainvoke/astream）、RunnableConfig 透传、可观测性接入，专家图单元测试可独立运行（假工具节点替换 LLM 节点）

**项目收获**：深入掌握 LangGraph 子图、状态映射、Checkpoint、Human-in-the-Loop 等核心机制，具备从零设计生产级 Agent 编排架构的能力。
