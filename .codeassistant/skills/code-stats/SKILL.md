# 代码规模统计

## 1. 跑统计脚本

技能自带 `scripts/stats.py`，用它统计：

```bash
run_skill_script(skill_name="code-stats", script="stats.py", arguments="--path .")
```

`arguments` 是传给脚本的命令行参数，脚本自己的参数见下：

- `--path` 统计的根目录，默认 `.`
- `--top` 输出最大的 N 个文件，默认 10

脚本只读，不会修改任何文件；执行脚本属于高危操作，会先请求人工审批。

## 2. 解读

拿到输出后给出一段简短结论：

- 各语言占比（行数，不是文件数）；
- 行数最多的几个文件是什么；
- 如果有明显的"超大文件"，提一句。

不要把脚本的原始输出整段粘回来，挑重点说。
